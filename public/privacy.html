Privacy notice

How this demo handles information

This project is an educational healthcare portal demo. Do not enter real patient or payment information.

Data handling

Local development uses the configured JSON fallback or MySQL database. Authenticated medical data is restricted by backend session and role checks. Production operators must configure secure hosting, encryption, backups, retention, access logging, and applicable privacy policies before using real data.

Contact and deletion

Use the configured support channel for data questions. This demo does not claim regulatory compliance or provide a complete legal data-subject request process.
